# Codex 无线墨水屏任务监控

**中文** | [English](README_EN.md)

社区链接：[LINUX DO](https://linux.do/)

![Codex 墨水屏实拍效果](docs/images/codex-eink-real-device.jpg)

> 用一块便宜的蓝牙墨水屏，通过**无线连接**显示 Codex 的额度和任务状态。

## 这是什么

这个小工具在 Windows 本机运行，把 Codex Desktop 的任务和额度放到一块桌面墨水屏上。电脑读取状态后，通过蓝牙无线发给屏幕；不需要给屏幕接数据线，也不需要刷固件或另接 ESP 开发板。

墨水屏不是手机屏幕：程序会尽快触发更新，但屏幕完成一次物理刷新通常还需要几秒，任务状态不会做到完全瞬时同步。实际延迟会随整屏刷新、蓝牙传输和设备状态变化。

如果想用很低的成本做一块桌面状态屏，这个项目就是为这种场景准备的。

## 你能看到什么

- 当前 Codex 侧栏中的任务名称、运行状态和步骤进度；
- 完成、失败和未读提醒；
- 主额度剩余百分比和重置日期；
- 最多 8 个底部状态位置，按上排 4 个、下排 4 个显示；
- 任务变化后尽快触发刷新，额度变化自动更新；屏幕实际显示可能延迟几秒。

按作者的购买体验，拼多多同类设备领券后大约 15 元；在当前低功耗更新策略下，续航预计仍约三个月。价格和续航会随活动、电池、刷新频率和设备批次变化，请以实际情况为准。在这种低成本组合里，它可能是目前能找到的最便宜的 Codex 额度监控方案之一。

## 2.0 版本更新

- **事件驱动刷新**：监听 Codex 本地状态变化，通常在变化后约 1 秒开始处理；30 秒（活跃任务）和 60 秒（空闲任务）轮询仅作为兜底。
- **刷新等待缩短**：活跃任务最多减少约 29 秒（约 97%），空闲任务最多减少约 59 秒（约 98%）；墨水屏自身的全屏物理刷新仍需要几秒。
- **更稳定的任务状态**：改进运行中任务、活动续接、计划步骤进度，以及完成、失败和未读提醒的识别，减少任务数量反复跳变。
- **更省电的 BLE 更新**：画面内容不变时不扫描、不连接、不上传，电压小幅波动也不会反复触发整屏刷新，因此续航预计仍约三个月。

## 屏幕怎么看

| 区域 | 示例 | 含义 |
| --- | --- | --- |
| 左上角 | `RUN 2` | `RUN`=运行中，`WAIT`=等待，`DONE`=完成，`ERR`=失败，`LIMIT`=额度用尽，`OFFLINE`=暂未同步，`IDLE`=空闲；数字是活跃任务数。 |
| 右上角 | `8.5` / `API` | `8.5` 是周额度重置日期（月.日）；`API` 表示 API 账户模式。 |
| 额度区 | `LEFT 35%` + 横条 | 主额度还剩 35%。 |
| 任务区 | `TASKS`、`>`、`?` | 显示 Codex 侧栏里的现有标题；`>` 表示运行，`?` 表示等待，不会重新生成英文任务名。 |
| 底部状态 | `●`、`2/5`、`✓`、`×` | 运行、步骤进度、完成、失败。完成和失败状态只保留未读提醒，最多两小时后自动清理。 |

## 需要什么

- Windows 电脑和 Codex Desktop；
- 一块支持 BLE 图片传输的 `SKD-CLOCK` 类墨水屏；
- 当前主要验证的是 212×104 单色屏；
- 电脑与墨水屏之间通过蓝牙无线连接。

其他尺寸或不同固件的设备可能不兼容。程序连接后会检查设备分辨率，发现不匹配时不会写入画面。

## 快速开始

在 PowerShell 进入项目目录：

```powershell
.\install.ps1
Copy-Item .\config.example.json .\config.json
```

在 `config.json` 填写蓝牙地址，或留空让程序扫描 `SKD-CLOCK` 设备，然后运行：

```powershell
.\start.ps1 preview --all --output previews  # 先看预览，不连接设备
.\start.ps1 probe                            # 检查设备
.\start.ps1 run                              # 启动无线监控
```

需要开机自动运行时：

```powershell
.\install-task.ps1
```

## 主要特点

- **无线更新**：电脑通过 Bluetooth 将画面发送到墨水屏；
- **快速跟随变化**：任务开始、步骤变化、完成、失败或未读变化后，通常约 1 秒内触发刷新；墨水屏完成物理刷新通常还需要几秒；
- **省电**：画面没有变化时不连接蓝牙，30/60 秒轮询只作为兜底；
- **本地隐私**：Codex 内容只在本机读取，不上传完整 prompt 或回复；
- **不改设备固件**：保留墨水屏原厂固件和协议。

## 项目边界

本项目不是 Codex 替代品，也不是云服务或通用墨水屏 SDK。它只负责把本机 Codex 的摘要状态无线显示在桌面屏幕上。
