# Codex 墨水屏监控

这是一个把 Codex Desktop 状态放到廉价蓝牙墨水屏上的本地小工具。它适合这样的人：想买一块便宜的 `SKD-CLOCK` 一类 212×104 单色墨水屏，放在桌面上持续看 Codex 额度和任务状态，而不必一直打开 Codex 窗口。

## 这个项目有什么用

Codex 在后台运行任务时，电脑上的窗口可能被其他工作遮住。这个程序会在本机读取 Codex 的会话、侧栏标题、未读标记和额度信息，生成一张适合墨水屏的黑白画面，再通过设备原有的 BLE 图片协议传过去。

墨水屏上主要显示：

- Codex 侧栏里当前正在运行的任务名称；
- 任务开始、步骤变化、完成、失败和未读状态；
- 主额度的精确剩余百分比和重置日期；
- 最多八格的运行/完成/失败状态图标，以及最多六行任务文字。

事件变化通常会在约 1 秒的合并窗口后触发刷新；蓝牙上传完成后还会再次检查期间到达的变化。30 秒（活跃任务）和 60 秒（空闲）轮询只作为事件遗漏或额度变化的兜底，不是正常状态变化必须等待的时间。

它不是 Codex 的替代品，也不是云端服务或通用墨水屏 SDK；它只负责把你本机 Codex 的摘要状态安静地放到桌面屏幕上。

## 适合的硬件

目前按 `SKD-CLOCK` 真机验证，常见特征是：

- 212×104 单色墨水屏；
- 原厂 DA14585 固件（固件 1.8 已验证）；
- 支持 BLE 图片写入；
- 不需要刷固件、接 ESP 开发板或开放 HTTP/LAN 服务。

不同批次或其他尺寸的设备可能使用不同协议。程序连接后会再次核对分辨率和状态包，发现不匹配时拒绝写入，避免把设备刷成不可用状态。

## 数据和隐私

所有读取和渲染都在本机完成，图片通过本机蓝牙发送到墨水屏。本项目不会把 prompt、回复内容或完整会话上传到云端，日志也只记录摘要和运行结果。设备地址、扫描参数和本机路径属于个人配置，不应提交到公开仓库；请从 `config.example.json` 复制出自己的 `config.json`。

## 安装与运行

在 Windows PowerShell 中进入项目目录，先创建虚拟环境并安装 Pillow、Bleak、Watchdog 等依赖：

```powershell
.\install.ps1
Copy-Item .\config.example.json .\config.json
```

然后在 `config.json` 中填写自己的墨水屏蓝牙地址（或保留为空，让程序扫描 `SKD-CLOCK` 前缀的设备），再运行：

```powershell
.\start.ps1 preview --all --output previews
.\start.ps1 probe
.\start.ps1 once
.\start.ps1 run
```

- `preview`：只生成 PNG，不连接设备。
- `probe`：连接并读取分辨率、固件、电压等状态，不写图片。
- `once`：内容变化时上传一帧；`--force` 可强制上传。
- `run`：常驻监控。事件变化会即时触发，活跃 30 秒、空闲 60 秒轮询作为兜底。
- `stats`：从 `logs/dashboard.log` 汇总每日 `uploaded/unchanged/retry`（观察中间态是否少刷）。

```powershell
.\start.ps1 stats
.\start.ps1 stats --day 2026-07-21
.\start.ps1 stats --day 2026-07-21 --hourly
.\start.ps1 stats --last-days 7
.\start.ps1 stats --json
```

本地部署使用项目根目录的 `config.json`：它选择竖版布局。公开仓库只提供不含个人设备地址的 `config.example.json`；首次使用时请复制并填写自己的配置。横版仍是默认布局；把其中的 `orientation` 改为 `landscape` 即可切回，不需要改协议或重新安装依赖。

## 自动启动

本机已经注册并启动计划任务 `Codex E-Ink Dashboard`。以下命令用于重装或恢复：

安装当前用户登录任务：

```powershell
.\install-task.ps1
```

停止并移除自动任务：

```powershell
.\uninstall-task.ps1
```

后台日志写入 `logs\dashboard.log`。任务设置为单实例，异常退出会最多重启三次，并记录 `service-start` / `service-exit` 生命周期。

计划任务允许在电池供电时启动，也不会因为切换到电池而停止。除登录触发外，还有每分钟一次的轻量看门狗触发；任务意外停止后会在下一分钟自动恢复。它不会唤醒或重启电脑，电脑睡眠期间暂停，唤醒后由 Windows 补跑。

## 刷新与省电

- **内容优先**：先用本地会话/额度 + 缓存的分辨率/电压生成位图并算 SHA-256；位图未变则**不扫描、不连接蓝牙**。
- 仅在位图变化（或 `--force`）时建立一次 BLE 连接：读状态 → 用滞回量化后的电压重渲染 → 同连接写图。
- 竖版右上角只显示周额度重置日期：`M.D`；API 计划显示 `API`。它不显示设备电压、`SYNC`、重置图标或具体时间。
- 额度显示实时接口返回的精确整数百分比；每变化 1% 都可能触发一次整屏刷新。
- 内容变化时发送 22 个 129 B 图像包，再发送一个 `0x62` 提交命令。
- 断线/GATT 瞬时错误时整帧从头重传（默认最多 2 次重试），不做不可靠的断点续传。

## 即时更新

- 后台监听 Codex 的会话、侧栏标题索引和未读状态文件。开始运行、计划步骤、完成、失败或未读标记变化后，会在 1 秒静默合并期结束后立即重新生成画面；每次重算同时读取最新额度，而不是等待下一次轮询。
- 图片哈希未变时不会扫描、连接或写入蓝牙；多个事件在一次 BLE 写入期间到达时会保留，并在上传结束后立刻重新检查。
- 活跃 30 秒、空闲 60 秒仍保留为文件事件遗漏和无本地事件额度变化的兜底，不再是正常状态变化的等待时间。
- 如果一次额度读取暂时失败，会保留上一次成功读取的实时百分比，避免墨水屏因为瞬时接口错误跳回旧值或出现误导性的变化。
- 任务名只使用 Codex 侧栏中的现有标题；没有现成标题时显示“未命名任务”，不会从英文请求、项目目录或任务 ID 生成替代名称。
- `state_5.sqlite` 与 `logs_2.sqlite` 只用于读取标题/活跃线程，不作为监听事件源，避免额度读取触发自身循环。

## 配置

复制 `config.example.json` 后，通过全局 `--config` 指定：

```powershell
.\start.ps1 --config .\config.json preview --all --output previews
```

常用项：

- `privacy_mode: "summary"`：显示任务标题与一行完成摘要。
- `privacy_mode: "titles"`：只显示标题，不显示完成摘要。
- `account_mode: "api"`：仅在已确认使用 API 账户时设置；跳过 ChatGPT 额度读取和本地额度回退，竖版右上角固定显示 `API`。默认值 `"auto"` 保留自动读取。
- `resolution`：默认从设备读取；除排查问题外不要手动填写。
- `image_index`：原厂图片槽，范围 0–6，默认 0。
- `orientation`：`landscape` 保留原横版；`portrait_cw` 为当前竖版；`portrait_ccw` 用于设备竖放方向相反时校正。竖版目前只支持本机的 212×104 面板。

## 竖版布局

竖版逻辑画布为 104×212，上传前旋转为设备要求的 212×104 原厂图像包。界面包含任务状态、主额度、运行任务和最近告警。顶部原 `SYNC` 区域现在显示周额度的重置日期，格式为 `M.D`，例如 `7.21`；优先取 `secondary` 周窗口，接口未提供它时回退到唯一可用的重置窗口。API 计划则显示 `API`，并隐藏主额度文字和额度条，同时将任务区贴到标题栏下方；当 Codex 明确返回 ChatGPT 额度鉴权不可用时，会自动识别为 API。已确认使用 API 的部署可设置 `account_mode: "api"`，避免瞬时读取失败时回退到历史重置日期。设备电压不再显示。

任务区下方是最多八格、按 4×2 对齐排列的状态条，不再显示完成任务标题或摘要。顺序固定为运行中、未读完成、失败：当前任务仅在本轮真实存在 `update_plan` 时显示 `当前步骤/总步骤`；没有结构化计划时显示运行符号，不会猜测进度。完成和失败任务都必须仍在 Codex Desktop 的本地未读（蓝点）列表中才显示，对勾和叉号不会为已读历史任务保留。运行、对勾和叉号都是复用的 7×7 单色像素位图，不使用 Unicode 字体，因此不需要为每次刷新重新绘制或依赖字体兼容性。任务文字区最多占六行，超出时最后一行显示 `...`。

## 蓝牙说明

设备当前回报 `allow_bluetooth=true`，通常会持续广播。如果以后扫描不到，可按一下设备按键，或等待它的广播窗口。程序连接后仍会再次核对分辨率；状态包异常、分辨率不一致或 MTU 不足时，图片写入会被拒绝。

程序不会执行 OTA、擦除固件、修改系统设置、删除相册，也不会开放 HTTP/LAN 服务。Codex 内容只在本机读取，日志不记录完整 prompt 或回复。
